== Description ==
GoTo AI helps WordPress admins quickly find and navigate to any admin screen using an AI-powered search modal.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/goto-ai` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
